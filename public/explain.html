Yunwu Image Generation API

Yunwu API provides full compatibility with the OpenAI /v1/images/generations endpoint. You can generate images directly using your configured API key.

API Endpoint:

POST https://yunwu.ai/v1/images/generations

cURL Call Example:

curl https://yunwu.ai/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "dall-e-3",
    "prompt": "a beautiful futuristic synthwave landscape with glowing neon towers, digital art",
    "n": 1,
    "size": "1024x1024"
  }'

Yunwu API Limit & Policy Report

Here is the gathered configuration context regarding limits for the Yunwu API (yunwu.ai) proxy service:

  • Rate Limits (Concurrency): Yunwu API advertises that there are no hard limits on concurrent requests for standard developer operations. High-throughput custom solutions are supported on demand by contacting their support team.
  • Free Tier Limitations: A free portal (free.yunwu.ai) is available via GitHub verification. It provides daily testing tokens for models like gpt-4o and gpt-4o-mini.
  • Billing & Payloads: Standard requests operate on a pre-paid balance scale (recharges starting as low as 1 RMB). Security measures such as optional request IP Whitelisting can be set in their developer console to prevent quota theft.

Playground Design & Features

This is a state-of-the-art Single Page Application (SPA) designed to act as a diagnostic dashboard for OpenAI-compatible APIs (configured to use the Yunwu API proxy by default).

Dual modes (Chat + Image Gen)
Frictionless mode switching using segmented tabs. Toggles between conversational text prompts and text-to-image workflows.
Image Gallery & Zoom
Renders generated images in a grid format with custom options to copy image URL, view in high resolution in a zoom lightbox, or download to device.
Diagnostic Inspect Panel
Provides a sliding drawer to view the exact JSON request body sent to the custom endpoint, and detailed error messages / status codes.
Dynamic Endpoint Switching
Automatically adjusts the API endpoint URL input between chat completions and image generation standard paths depending on active mode.
